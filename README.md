# 📚 مساعد تلخيص وتحليل المحاضرات (محلي بالكامل)

برنامج بواجهة رسومية بياخد محاضرات (PDF / Word / نص / فيديو / صوت)، يفهمها كـ"مرجع" خاص بيها،
يلخصها ويحللها باستخدام موديل AI مجاني شغال بالكامل على جهازك (من غير أي API مدفوع)،
وفي النهاية بيبني **مرجع شامل** واحد يجمع كل المحاضرات اللي عالجتها، تقدر تديه للطلاب.

---

## 1) المتطلبات قبل التشغيل

### أ) Python
لازم يكون عندك Python 3.10 أو أحدث. تأكد بالأمر:
```
python3 --version
```

### ب) Ollama (الموديل المجاني اللي هيعمل التلخيص)
1. حمّل وثبّت Ollama من الموقع الرسمي: https://ollama.com/download
2. بعد التثبيت، افتح Terminal وشغّل السيرفر (بيفضل شغال في الخلفية):
   ```
   ollama serve
   ```
3. في نافذة تانية، نزّل موديل مجاني (اختار واحد حسب قوة جهازك):
   - جهاز متوسط/قوي: `ollama pull qwen2.5:7b`
   - جهاز أضعف (لابتوب عادي بدون كارت شاشة قوي): `ollama pull llama3.2:3b`

   لو استخدمت موديل غير `qwen2.5:7b`، غيّر اسمه في خانة "اسم الموديل" داخل واجهة البرنامج.

### ج) ffmpeg (لو هتستخدم محاضرات فيديو/صوت)
- ويندوز: `winget install ffmpeg` أو حمّله من https://ffmpeg.org
- ماك: `brew install ffmpeg`
- لينكس: `sudo apt install ffmpeg`

### د) tkinter (الواجهة الرسومية) — على لينكس فقط غالباً محتاج تثبيته منفصل
```
sudo apt install python3-tk
```
(على ويندوز وماك بييجي مع Python تلقائي، مش محتاج تعمل حاجة)

---

## 2) تثبيت البرنامج

```bash
# داخل مجلد المشروع
python3 -m venv venv
source venv/bin/activate        # على ويندوز: venv\Scripts\activate

pip install -r requirements.txt
```

---

## 3) تشغيل البرنامج

تأكد إن `ollama serve` شغال، وبعدين:
```bash
python app.py
```

---

## 4) طريقة الاستخدام

1. دوس "➕ إضافة محاضرة" واختار ملف (PDF / Word / نص / فيديو / صوت)، وهيطلب منك تكتب اسم المحاضرة.
2. كرر الخطوة دي لأي عدد محاضرات عايز تضيفها دفعة واحدة.
3. دوس "🚀 معالجة الكل" — البرنامج هيقرا كل ملف (ويفرّغ الصوت/الفيديو لو محتاج)، ويبعت المحتوى للموديل المحلي عشان يلخصه ويحلله.
4. كل محاضرة بتتلخص باستخدام **محتواها هي بس** كمرجع (مش بتتخلط مع محاضرات تانية).
5. بعد ما يخلص، هتلاقي اسم المحاضرة ظاهر في "✅ المحاضرات المُلخّصة" — دوس عليه عشان تشوف الملخص.
6. دوس "📚 فتح المرجع الشامل لكل المحاضرات" عشان تشوف/تصدّر ملف واحد فيه كل المحاضرات اللي اتعملتلها تلخيص لحد دلوقتي — ده الملف اللي تديه للطلاب.
7. لو عايز تنشر الملخصات بشكل منسّق وجاهز للطباعة أو للفتح من الموبايل مباشرة، دوس "🌐 فتح المرجع الشامل كصفحة منسقة (HTML)"، أو اعمل دبل كليك على أي محاضرة في قايمة "✅ المحاضرات المُلخّصة" لفتح نسختها المنسقة لوحدها. كل محاضرة بتتحفظ تلقائياً بنسختين جوه `summaries/`: ملف `.md` خام، وملف `.html` بتصميم جاهز للنشر (تقدر تبعته للطلاب على طول أو تفتحه وتعمل "طباعة → حفظ كـ PDF").

---

## 5) هيكل الملفات اللي بيتبني تلقائي

```
lecture_ai/
├── app.py                  # الواجهة الرسومية
├── extractors.py           # استخراج النص من PDF/Word/نصوص
├── transcriber.py          # تفريغ الصوت/الفيديو (Whisper محلي)
├── ai_engine.py            # التلخيص والتحليل عبر Ollama
├── knowledge_base.py       # حفظ الملخصات وبناء المرجع الشامل (Markdown + HTML)
├── html_design.py          # تصميم صفحات النشر (HTML) الخاصة بالملخصات
├── summaries/              # ملخص كل محاضرة (.md + .html) في ملفات منفصلة (بيتبني تلقائي)
├── lectures_index.json     # فهرس المحاضرات المعالجة (بيتبني تلقائي)
├── المرجع_الشامل.md         # المرجع النهائي لكل المحاضرات - نسخة خام (بيتبني تلقائي)
└── المرجع_الشامل.html       # المرجع النهائي بتصميم جاهز للنشر/الطباعة (بيتبني تلقائي)
```

## 6) ملاحظات مهمة

- أول مرة تستخدم ملف صوت/فيديو، مكتبة Whisper هتنزل وزن الموديل مرة واحدة (محتاج نت وقتها بس، وبعدها شغال أوفلاين تماماً).
- كل حاجة بتشتغل محلياً على جهازك — مفيش داتا بتتبعت لأي سيرفر خارجي (باستثناء تحميل الموديلات أول مرة).
- لو المحاضرة طويلة جداً، البرنامج بيقسمها لأجزاء ويلخص كل جزء لوحده وبعدين يدمجهم في تحليل نهائي واحد.
- لو عايز جودة تلخيص أعلى وعندك جهاز قوي، جرب موديلات أكبر زي `qwen2.5:14b` أو `llama3.1:8b`.
